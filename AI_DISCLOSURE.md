# AI Disclosure

This project was built with the assistance of AI tools, primarily
[Claude](https://claude.ai) by Anthropic.

AI was used throughout the development process, including:

- Writing and refactoring Rust and TypeScript source code
- Designing the data model and library structure
- Debugging logic and edge cases
- Writing documentation

All AI-generated code was reviewed, tested, and accepted by the project
author. The project author is responsible for its content and behavior.

Using AI tools to help write software is increasingly common. This disclosure
is provided in the spirit of transparency.
